# PR safety plan

## Scope

Make PR #8 pass platform checks and resolve only justified security findings.
Keep user configs, installed applications, main, and vendored code unchanged.
Do not merge the PR, change branch protection, disable CodeQL, or invent authenticated download results.

## Options and decision

Installing Qt system libraries alone fixes CI but leaves CLI startup dependent on desktop libraries.
Changing ECB to another algorithm changes the upstream URL protocol and can break downloads.
Choose lazy GUI import plus Linux runtime prerequisites. Keep the protocol unchanged and review each alert in context.

## 1. CLI isolation

Add `tests/test_cli.py` with a fresh subprocess that rejects PyQt6 imports and exercises CLI help.
Verify failure before the change. Remove the eager GUI import from `src/downloader.py`.
Import the GUI only in the `--gui` path and `main_gui` entrypoint.
Test both entrypoints dispatch to the same launcher. Preserve existing CLI arguments and config behavior.

## 2. Linux GUI prerequisites

Modify `.github/workflows/application-ci.yml` to run CLI checks before installing any Linux GUI libraries.
Install libegl1 and libopengl0 on Ubuntu runners for the separate installed GUI smoke step.
Keep GUI smoke mandatory on all platforms. Validate workflow syntax and all six matrix jobs.
Document Linux desktop prerequisites in README.md.

## 3. Security review

Review `src/config.py` URL construction and the ECB test against bundled streamrip revision `095ec9fe0c1662b32b42e202d86dbc0159a94abf`.
Confirm encoded inputs contain public track metadata only, not ARLs, OAuth tokens, user credentials, or audio payloads.
Obtain an independent read-only review and document the scope in `docs/maintenance.md`.
Dismiss only PR alert #1 as a false positive if the protocol review confirms no confidentiality/security boundary.
Dismiss only PR alert #2 as used in tests if it decodes synthetic test data.
Use exact alert readback after updates. Keep CodeQL active and all other alerts untouched.

## 4. Verification and publication

Run CLI regressions, full pytest, Ruff, workflow validation, fresh wheel install, and installed CLI/GUI smoke.
Commit and push a focused follow-up under the existing PR publication authorization.
Update PR evidence and wait for platform and CodeQL checks. Request review only after green checks and release criteria assessment.
Live tests need explicit public/private playlist fixtures and an authorized download track. Do not read private credentials or download arbitrary media to fabricate acceptance.
If live fixtures or an independent approver are unavailable, leave the PR draft and state the minimal external action.

## Sources

Qt documentation identifies runtime system libraries as separate from packaged application dependencies.
GitHub documentation supports contextual dismissal of exact PR alerts with a reason.
The bundled streamrip source supplies the URL protocol evidence; changing the algorithm is outside this task.
